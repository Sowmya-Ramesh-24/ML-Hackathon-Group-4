About

PathSnap snaps noisy GPS traces to the road network. A machine-learning model scores candidate road segments for each GPS point, then an HMM with Viterbi decoding picks the most plausible continuous route.

  1. GPS observations + candidates
  2. ML match scores (p_match)
  3. HMM / Viterbi decode
  4. Route stretches on the map
